# The Door Was Push

A real private door-confusion log wearing an architectural grievance costume.

## What actually works

- First launch contains no fictional incident. File an actual door/place,
  mistake direction, 1–8 wrong attempts, 1–5 signage clarity, and optional note.
- Up to 75 local cases retain exact dates and produce incident, attempt,
  clear-sign, and most-common-mistake summaries.
- Any report can be reopened and corrected without creating a duplicate, or
  deleted individually. Confirmed complete erasure removes the draft and log.
- The UI labels every result self-reported and makes no sensor, location,
  accessibility, architectural-quality, or diagnostic claim.

No camera, location, notifications, backend, account, analytics, ads, or
network permission. Door incidents are already complete events, so there is no
useful future reminder to schedule.
