# Tiny Personal Museum

Photograph or describe ordinary objects before history carelessly forgets
them. Give each one the exhibition it deserves.

The private collection holds up to 30 exhibits. Each exhibit includes a title,
an optional curator story, a generated placard, and an optional photo.
Photos are resized, re-encoded to remove source metadata, and written with
complete file protection. The catalog survives relaunches, supports individual
deletion, and has a confirmed complete-erasure flow.

Photo-library selection and camera capture are user-initiated; camera permission
is requested only after Camera is tapped. Nothing is uploaded, synced,
published, or analyzed. No account, backend, analytics, ads, or network request
is made.
