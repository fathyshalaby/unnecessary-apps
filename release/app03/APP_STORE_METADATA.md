## Description

Do Not Text Them is a tiny emergency brake for the message you already suspect
is a terrible idea. Type the draft, survive a real ten-second cool-off, then
decide whether the evidence deserves deletion. The app never sends the message
for you—this intervention is between you and your better judgment. If you leave
the app, the deadline continues and an optional generic local notification marks
the end of the cool-off.

Features:

- A real ten-second countdown that survives interruption by calculating from a deadline.
- An optional generic local notification when the cool-off completes outside the app.
- Draft text that stays in memory only and is never sent or saved.
- A satisfying count of completed cool-offs and deleted drafts.
- A complete delete flow for when the evidence must disappear.

## Privacy submission draft

The current pilot source uses optional local notifications only; it does not use networking, create an account, or collect analytics. Draft content is intentionally memory-only, and notification text never includes it. Confirm these answers in App Store Connect after the signed archive is inspected.

## Review notes

The app is a private decision aid and does not send messages. Enter any sample text, tap Start the cool-off, allow notifications if desired, leave the app, wait ten seconds, return, then tap Delete the evidence to exercise the primary flow. No login or special hardware is required.
