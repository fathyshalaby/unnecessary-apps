# Unnecessary Apps Corp — support

## Start here

These apps are intentionally tiny and local. If a result looks absurd, that is
usually the feature. If a control does not respond, relaunch the app and try
its Reset or Clear control.

For the first release, the most useful report includes:

- app name and version/build;
- iPhone model and iOS version;
- the exact steps that produced the problem;
- whether the issue survives relaunch;
- a screenshot with private information removed.

Do not include passwords, private messages, medical reports, contact lists,
faces, or other sensitive material in a support request. GitHub issues are
public, so redact screenshots carefully.

## Permission problems

Photo, microphone, location, and Apple Health access is optional and only
appears in apps that use it. Access can be reviewed in iPhone Settings. The
HealthKit apps, Neighbor Noise Translator, Public Bathroom Quality Map, Quiet
Café Index, and Local Bench Reviews retain manual fallbacks if access is
denied.
Successful Apple Health reads require compatible data to exist on the device.

## Your data

Current releases have no account or cloud data store. Use the app's Reset or
Clear control to remove its applicable local record. Deleting an app removes
its local app container from the iPhone.

## Contact

Open a public support request at:

https://github.com/fathyshalaby/unnecessary-apps/issues/new

Use only a redacted screenshot and non-sensitive reproduction steps. You do
not need a GitHub account to read existing notices, but GitHub may require an
account to create a request.
