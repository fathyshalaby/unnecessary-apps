# Sleep Alibi

Enter your sleep and receive a defense for why you are useless today.

Sleep Alibi can optionally read recent sleep-analysis samples from Apple Health
over a 36-hour window when the user grants read-only access. The manual estimate and
generated alibi remain available when HealthKit is unavailable or permission is
denied. The imported duration is used in memory only and is never uploaded or
written back. After an explicit connection, read-only context refreshes on
relaunch; the user can switch back to a manual estimate at any time. An
optional quiet-hours-aware morning check-in is available. This
is a joke, not a sleep monitor, diagnosis, treatment, or medical recommendation.
