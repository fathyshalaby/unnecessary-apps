# Sock Tribunal

An unmatched sock gets a private case number, an evidence record, and a real
search status. Justice may be laundered.

## What actually works

- First launch is empty. File a description, color, pattern, optional last-seen
  location, and exact missing-since date for a real unmatched sock.
- The docket derives elapsed days from the date and keeps open, reunited, and
  closed-unsolved states. It never closes a case automatically.
- Published comic stages explain the generated court order; they are jokes, not
  evidence about where a sock went.
- Up to 75 user-owned cases persist locally with open/reunited/oldest summaries,
  priority ordering, status changes, reopening, individual deletion, draft
  clearing, and confirmed complete erasure.
- A case can carry one optional 1–14 day local recheck. Permission is requested
  only when filing a reminded case; resolving, deleting, evicting, or erasing a
  case cancels its notification.
- Reminders use generic lock-screen copy and the shared 09:00–20:30 quiet-hours
  policy.

No backend, account, analytics, ads, photos, contacts, or network permission.
