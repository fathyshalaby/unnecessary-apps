# Health Data Horoscope

Turn steps and sleep into an obviously fictional horoscope.

The user can optionally read today’s steps and recent sleep duration from Apple
Health, or enter both manually. Imported values are read-only, processed on the
device, and used only as inputs to entertainment. The result is explicitly not
health interpretation, prediction, treatment, or advice. An optional
quiet-hours-aware daily constellation reminder is available. After an explicit
connection, read-only context refreshes on relaunch; the user can switch back
to manual numbers at any time.
