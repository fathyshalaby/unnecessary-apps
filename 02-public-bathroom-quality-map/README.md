# Public Bathroom Quality Map

Search the visible Apple map for possible public restrooms, or place a manual
map pin after visiting one, then save a private quality report.

Cleanliness, privacy, supplies, queue length, changing-table observation,
coordinates, and notes persist locally. Optional When In Use location access
only recenters the map after the user taps the location button. Apple MapKit
supplies map and search content. Results are not emergency, opening-hours, or
accessibility guarantees and must be verified on arrival. There is no account,
analytics, advertising, cloud report database, or public publishing.
