# The Recovery Goblin

A tiny check-in that gives your tiredness and soreness a fictional goblin ruling.

The user’s own tiredness and soreness remain the real inputs. Apple Health is an
optional read-only context card for today’s workout duration; it is not used to
calculate a recovery score. The ruling is a playful option, not a coach,
diagnosis, prescription, or medical advice. After an explicit connection, the
read-only context refreshes on relaunch. An optional quiet-hours-aware daily
check-in is available.
