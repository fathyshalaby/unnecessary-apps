# Walking Meeting Escape Plan

A real local walking-meeting session tool wearing an office-escape costume.

## What actually works

- First launch has no fictional meeting. Enter a title, one decision/objective,
  optional route or accessibility note, and a 10–120 minute plan.
- A live elapsed/remaining timer derives from the stored start date and survives
  relaunch rather than pretending the app remained in the foreground.
- Mark objective, decision, and next-step checkpoints; add up to 30 timestamped
  field notes; finish normally or preserve an honest ended-early outcome.
- Up to 40 private sessions retain exact planned/actual time, checkpoints,
  notes, outcome, and date, with useful totals, individual deletion, and
  confirmed complete erasure.
- An optional one-shot planned-end notification is requested only in context,
  uses generic lock-screen copy, follows shared quiet hours, and is cancelled
  when the session finishes or is erased.

No Calendar, location, step, route-safety, participant, microphone, backend,
account, analytics, ads, or network access.
