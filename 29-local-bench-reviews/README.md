# Local Bench Reviews

Pan an Apple map, place the center pin on a bench, and review it by comfort,
shade, view, and whether a pigeon has already claimed the armrest.

Bench coordinates, ratings, and notes persist in a private on-device journal.
When the user explicitly taps the location button, optional When In Use access
recenters the map; the complete map-and-review flow also works without location
permission. Map content is supplied by Apple MapKit. There is no account,
analytics, advertising, cloud database, or public publishing.
