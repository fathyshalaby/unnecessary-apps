# Quiet Café Index

Search the visible Apple map for real cafés, or place a manual map pin, then
rate whether a person can sit alone without being spiritually perceived.

Quietness, seating, outlet odds, solo-friendliness, visit period, coordinates,
and notes persist in a private on-device journal. Optional When In Use location
access only recenters the map after the user taps the location button. Apple
MapKit supplies map and venue-search content. There is no account, analytics,
advertising, cloud review database, or public publishing.
