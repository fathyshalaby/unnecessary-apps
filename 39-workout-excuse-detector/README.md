# Workout Excuse Detector

Compare your stated excuse with the activity you actually did. The detector is rude but supportive.

The excuse and result persist locally. Workout Excuse Detector can optionally
read today’s workout durations from Apple Health with read-only access; the
manual movement estimate remains available when HealthKit is unavailable or
permission is denied. Imported duration is used in memory only and is never
uploaded or written back. After an explicit connection, read-only context
refreshes on relaunch; the user can switch back to manual movement at any time.
An optional quiet-hours-aware daily case check-in is available. Empty input is
handled, and the case can be reset.
This is fitness-culture satire, not a diagnosis, training plan, or health
recommendation.
