# Tiny Gratitude

Only microscopic gratitude is accepted. “The elevator arrived” counts.

## What actually works

- A bounded journal accepts a 180-character tiny win, a category, and a timestamp.
- The dashboard reports today’s entries, the total archive, and unique days.
- The five newest entries appear first, with an explicit control to browse all
  saved entries; up to 100 are retained on-device.
- Entries can be deleted individually, resurfaced at random, or erased together
  after destructive confirmation.
- Existing entries migrate into the richer format without being discarded.
- Entries survive relaunch without an account, network request, or cloud sync.

This app has no backend, analytics, ads, or network permission.
