# Unnecessary Apps social production

This folder turns the strategy in `docs/` into an executable publishing workflow.

## Start here

1. Import `calendar/launch-week.ics` into your calendar.
2. Open `launch-week/LAUNCH_WEEK.md` for exact post copy and publishing order.
3. Film against `launch-week/CAPTURE_MANIFEST.md`.
4. Use the full shot-by-shot scripts in `../docs/SOCIAL_SCRIPTS_SEASON_1.md`.
5. Enter seven-day results in `launch-week/METRICS.md` before changing the format.

## Working folder convention

Create these folders in your editor or media drive when footage exists:

```text
social/launch-week/media/
├── 00-trailer/
│   ├── raw/
│   ├── screen/
│   ├── audio/
│   └── exports/
├── 01-mascot-reveal/
├── 02-three-app-montage/
├── e01-chair-finder/
├── e02-do-not-text-them/
└── e03-the-door-was-push/
```

Do not commit raw footage containing private notifications, email, health information, receipts, exact location history, or identifiable strangers without consent.

## File naming

```text
UA_S01_E01_CHAIRFINDER_CAM_A_001.mov
UA_S01_E01_CHAIRFINDER_SCREEN_001.mov
UA_S01_E01_CHAIRFINDER_MASTER_V01.mp4
UA_S01_E01_CHAIRFINDER_COVER_V01.png
```

Keep clean masters free of TikTok, Instagram, or YouTube watermarks.
