# Chair Finder

The municipal-grade answer to: “Which of these chairs should I actually sit on?”

Create a private shortlist from chairs you can really see, rate comfort, shade,
and pigeon risk, add a field note, and ask the seating inspector to rank the
evidence. Up to 20 observations persist locally across launches.

Chair Finder contains no seeded places and does not claim to discover nearby
furniture. It uses no location, account, backend, analytics, ads, or network
request. Individual observations can be deleted; clear-all erases the complete
local archive and ranking after confirmation.
