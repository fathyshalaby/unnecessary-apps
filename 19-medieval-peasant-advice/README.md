# Bad Advice from a Medieval Peasant

Ask a question. Receive guidance from someone who has seen one castle.

## What actually works

- On supported iOS 26 devices, Apple Foundation Models generates a short
  medieval-peasant response on-device.
- If the Apple model is unavailable (including the simulator), the app uses a
  deterministic local village backup.
- The question and answer survive relaunch and can be cleared explicitly.
- Empty questions receive a useful error response rather than a blank result.

No cloud AI service, backend, account, analytics, ads, or network permission.
