# The Last Slice

A real local fairness rotation disguised as a tiny diplomatic crisis.

## What actually works

- First launch has no fictional people or ruling history. Enter 2–20 actual
  participants and the item being awarded.
- The published rule selects from the fewest previous awards among the current
  eligible roster; only a tie is randomized locally.
- A selected candidate can claim the item or pass. Passing removes that person
  only from the current round, and an all-pass round records no award.
- The active ruling survives relaunch. Up to 50 completed rulings retain the
  roster, winner or unclaimed outcome, passes, and date.
- Award, pass, and ruling summaries, per-ruling deletion, and confirmed
  complete erasure keep the fairness history understandable and controllable.

No Contacts access, notifications, backend, account, analytics, ads, or
network permission. A live group decision has no useful future reminder, so
this app deliberately sends none.
