# Unnecessary Apps — Season 1 scripts

These scripts are written for a single 9:16 master that can be posted to TikTok, Instagram Reels, and YouTube Shorts. Delivery is dry, fast, and completely serious. The UI and mascot carry the color; the creator behaves as if this is routine government work.

## Reusable language

**Primary opener:** “This problem did not need an app. So I built one.”

Rotate these alternatives so the phrase stays recognizable without becoming mechanical:

- “Society ignored this problem, so I made it worse with software.”
- “Nobody asked for this. Unfortunately, I know how to code.”
- “I found a problem too small to matter and gave it a product team.”
- “This could have remained a thought. It is now an iPhone app.”

**Primary close:** “What problem should not become an app next?”

**Release-state closes:** use only the line that is currently true.

- Not released: “Should I release this or delete the source code?”
- Testing: “It is in TestFlight because apparently we have learned nothing.”
- Released: “It is unfortunately real. The link is in my bio.”

## Caption template

```text
I built [APP] because [tiny recognizable problem].

[One sentence explaining the honest current behavior.]

[One specific question]?

#UnnecessaryApps #[AppName] #IndieDev
```

Keep captions concise enough that the premise appears before truncation. Use three relevant hashtags as a starting point; do not stuff unrelated tags.

## Story cutdowns

Every main episode creates four low-effort Stories:

1. **Before:** a poll — “Does this problem deserve an app? Yes / absolutely not.”
2. **Build:** icon or mascot vote.
3. **After:** result screenshot plus reaction slider.
4. **Next:** two possible app names or problems.

## Editing rules

- Export 1080 × 1920, 9:16, with no platform watermark.
- Put a visual, verbal, and text hook in the first second.
- Keep captions to two lines and roughly three-to-five words per line.
- Cut every pause that does not improve the deadpan joke.
- Keep phone interactions large enough to read without pausing.
- Use original voice as the default; music sits quietly underneath.
- Never expose notifications, email addresses, health information, receipts, location history, or identifiable strangers.
- Never pretend manual input is live sensing, mapping, AI, or HealthKit.
- Never say an app is downloadable until the link works.
