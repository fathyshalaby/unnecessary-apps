# Rest Day Police

Issue yourself a fictional citation when you train too many days in a row.

The user can optionally read recent Apple Health workout entries to count
consecutive active days. The app reads only; it never writes or uploads health
data. A manual fictional streak remains available when HealthKit is unavailable
or denied. After an explicit connection, read-only activity context refreshes
on relaunch; the user can switch back to a manual streak at any time. An
optional quiet-hours-aware officer check-in is available.
